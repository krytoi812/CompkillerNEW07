# Список тестов

## Идентификаторы и ключевые слова

- Разбор идентификаторов: x summa _counter _counterspEll BaSHmAK value2
- Слова-префиксы ключевых слов не являются ключевыми: iffy mainx — идентификаторы
- Ключевые слова в любом регистре: main MAIN if If ELSE while For return var STRUCT class — вид лексемы не зависит от регистра
- Ключевые слова типов в любом регистре: float FLOAT Float, string STRING String, bool BOOL Bool
- Зарезервированные слова логических операторов в любом регистре: and OR not — KeywordAnd, KeywordOr, KeywordNot
- Логические литералы в любом регистре: true false TRUE False — BooleanLiteral
- Написание лексемы сохраняется в исходном регистре: BaSHmAK — Value = "BaSHmAK"
- Идентификаторы только из ASCII-символов: A-Z, a-z, 0-9, _

## Литералы

- Разбор литералов целых чисел: 0 314 007
- Разбор литералов вещественных чисел: 3.14 0.5 123.456
- Целое число с точкой без цифр после неё: 1. — лексемы IntegerLiteral("1") и Dot
- Точка перед цифрой без целой части: .5 — лексемы Dot(".") и IntegerLiteral("5")
- Разбор строк: "Hello, world!" "Привет, мир!"
- Пустой строковый литерал: "" — Value = ""
- Разбор escape-последовательностей: "a\nb\t\"c\\d" — Value хранит расшифрованное содержимое
- Перенос строки внутри строкового литерала: "line1
line2" — символ переноса сохраняется в Value, нумерация строк продолжается
- Обозначения комментариев внутри строки: "// это не комментарий /* и это тоже */" — обычный текст

## Операторы, разделители и скобки

- x + y / (10 - z * 2) — комбинация арифметических операторов и скобок
- speed <= limit && limit >= 0 || !flag — комбинация операторов сравнения и логических
- v[0] = speed.x; — квадратные скобки, точка, присваивание, точка с запятой
- struct Pair { int a, b; } — объявление структуры: фигурные скобки, запятая, точка с запятой
- main var x = 10 + 2.5; — полная последовательность лексем небольшой программы

## Пробелы и комментарии

- Пропуск пробельных символов: ' ', '\t', '\r', '\n' — источник только из пробелов даёт одну лексему EndOfFile
- Однострочный комментарий: x // пояснение до конца строки
y — комментарий не даёт лексем
- Однострочный комментарий в конце файла без перевода строки: x // пояснение
- Многострочный комментарий с переносами: a /* одна
две */ b — комментарий не даёт лексем, нумерация строк продолжается
- Вложенная запись /* /* */ завершается на первом */

## Позиции лексем

- Пустой источник — одна лексема EndOfFile в позиции 1:1
- Номера строк и колонок в многострочном источнике: x =
  42; — позиции каждой лексемы
- Номера строк и колонок в источнике с CRLF-переводами: x =
  42; — CRLF считается одним переводом строки
- Загрузка исходного текста из файла: Lexer.FromFile(path) читает файл через File.ReadAllText

## Ошибки

- Неизвестные символы: @ #
- Одиночные & и | вместо парных && и ||
- Незакрытая строка: "abc
- Незакрытая строка с экранирующим символом на конце: "abc\
- Неизвестная escape-последовательность: "a\qb"
- Незакрытый многострочный комментарий: a /* начало
- Попытка загрузки несуществующего файла: Lexer.FromFile(path) выбрасывает FileNotFoundException
