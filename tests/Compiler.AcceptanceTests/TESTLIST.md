# Приёмочные тесты интерпретатора

Тесты вызывают `Program.Run`, как и консольная точка входа `Main`. Исходный код читается из временного файла, `StringReader` задаёт stdin, два `StringWriter` перехватывают stdout и stderr. Выполняются лексер, парсер (построение AST) и вычислитель AST, проверяются вывод, диагностика и код завершения.

Сценарии арифметики и CLI находятся в `InterpreterTests.cs`, переменных и функций — в `VariablesAndFunctionsTests.cs`. Класс `SourceFile` создаёт отдельный файл для каждого теста и удаляет его после завершения.

## Правила и альтернативы EBNF

| Правило | Проверяемые варианты | Примеры из `ValidPrograms` |
| --- | --- | --- |
| `program` | Функции перед одним `main`, пустой блок и несколько инструкций | `main {}`, `int answer() { return 42; } main { print answer(); }` |
| `functionDeclaration` | Типы `int`/`void`, с параметрами и без них | `answer`, `add`, `show` в `VariablesAndFunctionsTests.ValidPrograms` |
| `parameterList`, `parameter` | Один и несколько параметров `int` | `f(int x)`, `add(int a, int b)` |
| `block` | Пустое тело, вложенные блоки, перекрытие имени | `main { int x = 1; { int x = 2; print x; } print x; }` |
| `statement` | Выражение, `print`, объявление, блок, `return` со значением и без | Арифметические программы, `add`, `show`, примеры с вложенными блоками |
| `variableDeclaration` | Тип `int`, имя, обязательный инициализатор | `main { int x = 3; print x + 5; }` |
| `expression`, `assignment` | Без присваивания, присваивание с результатом, цепочка справа налево | `a = b = 7`, `1 + (x = 3)` |
| `additive` | Без продолжения; `+`; `-`; левая ассоциативность | `42`, `2 + 3`, `10 - 3 - 2` |
| `multiplicative` | Без продолжения; `*`; `/`; `%`; левая ассоциативность | `42`, `2 + 3 * 4`, `20 / 5 / 2`, `17 % 5` |
| `unary` | С минусом и без него; приоритет ниже степени | `42`, `-(5 + 3)`, `-2 ^ 2` |
| `power` | Без степени; степень; правая ассоциативность | `42`, `(-2) ^ 2`, `2 ^ 3 ^ 2` |
| `primary` | Литерал, переменная, вызов функции, `readInt()`, скобки | `42`, `x`, `add(2, 3)`, `readInt()`, `(2 + 3) * 4` |
| `callArguments`, `argumentList` | Вызовы без аргументов, с одним и несколькими аргументами | `answer()`, `abs(-7)`, `add(2, 3)` |

## Корректные программы

- Пример из задания с ожидаемым результатом 80.
- Вычисление площади прямоугольника по двум числам из stdin: 6 и 7 дают 42.
- Приоритеты операций, скобки, левая ассоциативность вычитания и деления, правая ассоциативность степени.
- Отрицательные операнды деления и остатка; целочисленное деление округляется к нулю.
- Выражения без `print` выполняются без вывода; несколько инструкций выполняются по порядку.
- Вызовы `readInt()` читают отдельные строки слева направо, в том числе в инструкции без вывода.
- Ключевые слова в верхнем регистре, ведущие нули, комментарии, CRLF, NBSP, вертикальная табуляция и перевод страницы.
- Границы long: максимальный литерал, минимальное значение из ввода, выражения и степени.
- `0 ^ 0`, нулевой показатель, большие показатели при основаниях 0, 1 и -1; чётность показателя при основании -1.

## Ошибки

- Отсутствие `main`, открывающей/закрывающей скобки или точки с запятой, незакрытые круглые скобки, второй `main`, пустое выражение.
- Необъявленные переменные, неподдерживаемое объявление через `var`, вещественные/строковые/логические литералы.
- Неизвестный символ и незакрытый комментарий.
- Деление и остаток от деления на ноль, отрицательная степень, слишком большой литерал.
- Переполнение сложения, вычитания, умножения, деления, остатка, унарного минуса и степени.
- EOF при вводе, пустая строка, текст, дробь, переполнение и два числа на одной строке.
- Синтаксическая ошибка обнаруживается на этапе построения AST, до начала вычислений: ни одна инструкция не выполняется, stdout пуст.
- После ошибки арифметики или ввода последующие инструкции не выполняются; вывод инструкций, выполненных до ошибки, сохраняется.
- Отсутствующий/лишний аргумент CLI, отсутствующие файл и каталог, каталог вместо файла.

Для ошибки ожидаются код 1 и диагностическое сообщение в stderr. При синтаксической ошибке stdout пуст, поскольку разбор всей программы выполняется до вычислений; при ошибке времени выполнения stdout содержит вывод инструкций, успевших выполниться до ошибки.

## Переменные и функции

- Объявление с типом и начальным значением, чтение, изменение, использование в арифметике.
- Значение присваивания, его низкий приоритет и правая ассоциативность цепочек.
- Регистронезависимые имена, запрет повторного объявления в одной области.
- Вложенные блоки, перекрытие имени, изменение внешней переменной, исчезновение локального имени после блока.
- Лексическая область функции: переменные main и вызывающей функции недоступны.
- Функции с параметрами и без них, вложенные и опережающие вызовы, параметры по значению.
- Раздельные пространства имён функций и переменных.
- Функции `int`/`void`, явный возврат и завершение `void` по концу тела, возврат из вложенного блока.
- Восстановление состояния вызывающей функции после возврата из другой функции.
- Аргументы слева направо; функция и арность проверяются до вычисления аргументов.
- `abs`, `min`, `max`, вложенные вызовы, один и несколько аргументов `min`/`max`.
- Ошибки имён, инициализации, целей присваивания, параметров, вызовов и возврата.
- Переполнение `abs`, запрет значения от `void`, ограничение глубины вызовов.
- Остановка на ошибке внутри функции с сохранением предшествующего вывода.

Две полные программы берутся из каталога `examples` и копируются в тестовый каталог при сборке: `rectangle.ck` вычисляет площадь прямоугольника по двум точкам, `order.ck` — стоимость покупок с доставкой. Эти же файлы можно запускать через CLI.

## Запуск и покрытие

```sh
dotnet test tests/Compiler.AcceptanceTests
```

Скрипты `scripts/run-tests-with-coverage.ps1` и `scripts/run-tests-with-coverage` создают HTML-отчёт `tests/coverage-report/index.html`. Line coverage класса `Parsing.Parser` должно быть не ниже 80%. Результаты проверки приведены в [COVERAGE.md](COVERAGE.md).
