# Список тестов лексического анализатора

## Идентификаторы и ключевые слова

- Разбор идентификаторов: `x`, `summa`, `_counter`, `_counterspEll`, `BaSHmAK`, `value2`.
- Слова, начинающиеся с ключевого слова, не распознаются как ключевые: `iffy` и `mainx` — идентификаторы.
- Ключевые слова распознаются без учёта регистра: `main`, `MAIN`, `if`, `If`, `ELSE`, `while`, `For`, `return`, `var`, `STRUCT`, `class`.
- Ключевые слова типов распознаются без учёта регистра: `float`, `FLOAT`, `Float`, `string`, `STRING`, `String`, `bool`, `BOOL`, `Bool`.
- Логические операторы-слова распознаются как ключевые слова: `and`, `OR`, `not`.
- Ключевое слово вывода распознаётся без учёта регистра: `print`, `PRINT`.
- Встроенная функция чтения распознаётся без учёта регистра: `readInt`, `READINT`, `ReadInt`.
- Логические литералы распознаются как `BooleanLiteral`: `true`, `false`, `TRUE`, `False`.
- Исходное написание лексемы сохраняется: `BaSHmAK` возвращается в `Value` без изменения регистра.

## Числовые литералы

- Разбор целых чисел: `0`, `314`, `007`.
- Разбор вещественных чисел: `3.14`, `0.5`, `123.456`.
- Запись `1.` разбирается как `IntegerLiteral("1")` и `Dot`.
- Запись `.5` разбирается как `Dot(".")` и `IntegerLiteral("5")`.
- Целые числа с ведущими нулями сохраняют исходное написание в `Value`.

## Строковые литералы

- Разбор строк на латинице и кириллице: `"Hello, world!"`, `"Привет, мир!"`.
- Пустая строка `""` распознаётся как `StringLiteral` с пустым `Value`.
- Декодирование управляющих последовательностей в исходной строке: `"a\nb\t\"c\\d"`.
- Фактический перевод строки внутри кавычек сохраняется в `Value`; номер строки следующей лексемы увеличивается.
- Обозначения `//`, `/*` и `*/` внутри строки считаются обычным текстом.

## Операторы, разделители и скобки

- Односимвольные операторы: `+`, `-`, `*`, `/`, `%`, `^`, `=`, `!`, `<`, `>`.
- Двухсимвольные операторы: `==`, `!=`, `<=`, `>=`, `&&`, `||`.
- Слова `and`, `or`, `not` распознаются как ключевые слова логических операций.
- Проверка последовательности арифметических лексем и круглых скобок: `x + y / (10 - z * 2)`.
- Проверка последовательности операторов сравнения и логических операторов: `speed <= limit && limit >= 0 || !flag`.
- Проверка квадратных скобок, присваивания и доступа к полю: `v[0] = speed.x;`.
- Проверка лексем объявления структуры: `struct Pair { int a, b; }`.
- Проверка последовательности лексем небольшой программы: `main var x = 10 + 2.5;`.

## Пробельные символы и комментарии

- Пробелы и управляющие пробельные символы пропускаются: пробел, табуляция, LF, CRLF, неразрывный пробел, вертикальная табуляция и перевод страницы.
- Однострочный комментарий пропускается до конца строки: `x // комментарий`.
- Однострочный комментарий в конце файла без перевода строки пропускается.
- Многострочный комментарий пропускается, а нумерация строк после него сохраняется корректной: `a /* первая\nвторая */ b`.
- Вложенные комментарии не поддерживаются: `/* /* */` завершается на первом `*/`.

## Позиции лексем и загрузка файла

- Пустой исходный текст возвращает только `EndOfFile` с позицией 1:1.
- Для многострочного текста проверяются номера строк и колонок лексем.
- Для CRLF проверяется, что пара символов считается одним переводом строки.
- `Lexer.FromFile(path)` читает содержимое существующего файла.
- При попытке загрузить несуществующий файл возникает `FileNotFoundException`.

## Ошибки лексического анализа

- Неизвестные символы: `@`, `#`.
- Одиночные `&` и `|` вместо `&&` и `||`.
- Незакрытая строка: `"abc`.
- Строка, заканчивающаяся одиночным символом `\`: `"abc\\`.
- Неизвестная управляющая последовательность: `"a\qb"`.
- Незакрытый многострочный комментарий: `a /* начало`.
