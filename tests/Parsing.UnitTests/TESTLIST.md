# Список тестов парсера и интерпретатора

## Корректные программы

- Пустая программа: `main { }` — вывода нет.
- Приоритет умножения: `main { print 2 + 3 * 4; }` — вывод `14`.
- Скобки меняют приоритет: `main { print (2 + 3) * 4; }` — вывод `20`.
- Левая ассоциативность вычитания: `main { print 10 - 3 - 2; }` — вывод `5`.
- Целочисленное деление: `main { print 7 / 2; }` — вывод `3`.
- Остаток от деления: `main { print 17 % 5; }` — вывод `2`.
- Правая ассоциативность степени: `main { print 2 ^ 3 ^ 2; }` — вывод `512`.
- Степень имеет более высокий приоритет, чем унарный минус: `main { print -2 ^ 2; }` — вывод `-4`.
- Унарный минус перед выражением в скобках: `main { print -(5 + 3); }` — вывод `-8`.
- Унарный минус: `main { print -5 + 3; }` — вывод `-2`.
- Выражение без `print` вычисляется, но не выводится: `main { 1 + 1; }`.
- Несколько инструкций `print` выводят значения по одному на строку.
- Однострочные и многострочные комментарии вокруг программы не мешают разбору.

## Встроенная функция readInt()

- Чтение положительного целого числа: `main { print readInt(); }`.
- Чтение отрицательного целого числа и использование результата в выражении: `main { print readInt() + 8; }`.
- Использование результата чтения в возведении в степень: `main { print readInt() ^ 2; }`.
- Несколько вызовов `readInt()` читают отдельные строки входного потока.
- Пробелы вокруг введённого числа и знак `+` обрабатываются корректно.
- Чтение минимального значения знакового 64-битного целого типа: `-9223372036854775808`.

## Граничные значения арифметики

- `main { print (-2) ^ 63; }` — результат `-9223372036854775808`.
- `main { print 0 ^ 0; }` — результат `1`.

## Ошибки разбора и выполнения

- Нет ключевого слова `main`: `{ print 1; }`.
- Нет открывающей фигурной скобки: `main print 1; }`.
- Нет точки с запятой: `main { print 1 }`.
- Пустое выражение: `main { print ; }`.
- Не закрыта круглая скобка: `main { print (1; }`.
- Не закрыт блок программы: `main { print 1;`.
- Лишняя лексема после программы: `main { print 1; } }`.
- Деление на ноль: `main { print 1 / 0; }`.
- Остаток от деления на ноль: `main { print 5 % 0; }`.
- Отрицательный показатель степени: `main { print 2 ^ -1; }`.
- Переполнение при сложении: `main { print 9223372036854775807 + 1; }`.
- Переполнение при умножении: `main { print 9223372036854775807 * 2; }`.
- Переполнение при возведении в степень: `main { print 2 ^ 64; }`.
- Отрицание минимального значения, полученного через `readInt()`, вызывает ошибку переполнения.

## Ошибки ввода readInt()

- Пустой входной поток (EOF) при вызове `readInt()` вызывает ошибку.
- Нечисловой ввод, например `abc`, вызывает ошибку.
- Вещественное число, например `1.5`, не принимается как целое.
- Число за пределами диапазона знакового 64-битного типа вызывает ошибку.
