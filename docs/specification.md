# Спецификация языка CompkillerNEW07

## Введение

CompkillerNEW07 — учебный императивный язык. Программа хранится в одном файле, точка входа — `main`.

Язык поддерживает целочисленные выражения, переменные типа `int`, присваивание, вложенные блоки и пользовательские функции. Для вывода используется инструкция `print`, для ввода — `readInt()`. Встроенные функции `abs`, `min` и `max` работают с целыми числами. Вещественные числа, строки, логические выражения, условия, циклы, массивы, структуры и классы пока не поддерживаются синтаксическим анализатором.

Лексический анализатор уже распознаёт некоторые лексемы будущих итераций. Само по себе распознавание такой лексемы не означает, что соответствующая конструкция разрешена синтаксисом текущей версии языка.

## Лексика

Исходный текст состоит из идентификаторов, ключевых слов, литералов, операторов и разделителей. Комментарии и пробельные символы вне строк пропускаются.

### Ключевые слова

Лексический анализатор распознаёт следующие зарезервированные слова:

`main`, `if`, `else`, `while`, `for`, `return`, `var`, `int`, `void`, `float`, `string`, `bool`, `true`, `false`, `struct`, `class`, `and`, `or`, `not`, `print`, `readInt`.

Зарезервированные слова нельзя использовать как идентификаторы. В текущем синтаксисе используются `main`, `int`, `void`, `return`, `print` и `readInt`; остальные слова зарезервированы для последующих итераций. `void` обозначает отсутствие возвращаемого значения, а не отдельный тип данных. Имена `abs`, `min`, `max` распознаются как идентификаторы, но зарезервированы в пространстве имён функций.

### Идентификаторы

Идентификатор начинается с ASCII-буквы (`A`–`Z`, `a`–`z`) или символа `_`. Далее допускаются ASCII-буквы, ASCII-цифры (`0`–`9`) и символ `_`.

Примеры: `x`, `summa`, `_counter`, `user1`.

Регистр в идентификаторах и ключевых словах не учитывается. Например, `MAIN` распознаётся как ключевое слово `main`, а написания `summa` и `SUMMA` обозначают одно имя. В строковых литералах регистр сохраняется.

### Литералы

Целочисленный литерал состоит из одной или нескольких цифр `0`–`9`. Ведущие нули разрешены: `007` обозначает десятичное число 7. Лексический анализатор распознаёт последовательность цифр; при вычислении литерал должен помещаться в диапазон `0`…`9223372036854775807` (диапазон `long` в C# для неотрицательного литерала).

Вещественные числа (`float`): цифры, точка и цифры. С обеих сторон точки обязательна хотя бы одна цифра. Примеры: `3.14`, `0.5`, `3.0`. Записи `.5` и `3.` не являются отдельными числовыми литералами. Экспоненциальная запись (`1e3`) не поддерживается. Вещественные литералы распознаются лексером, но не принимаются грамматикой текущей версии.

Строки (`string`): текст в двойных кавычках. Разрешены ровно четыре управляющие последовательности: `\\` — обратная косая черта, `\"` — кавычка, `\n` — перевод строки, `\t` — табуляция. Остальные последовательности после `\` считаются ошибкой. Пустые строки и фактические переносы строк между кавычками разрешены. Отсутствие закрывающей кавычки — ошибка. Строковые литералы распознаются лексером, но не принимаются грамматикой текущей версии.

Логические значения (`bool`): `true` и `false`. Они распознаются лексером, но пока не принимаются грамматикой текущей версии.

### Операторы и разделители

| Категория | Обозначения |
|---|---|
| Арифметические | `+`, `-`, `*`, `/`, `%`, `^` |
| Присваивание | `=` |
| Сравнения | `==`, `!=`, `<`, `<=`, `>`, `>=` |
| Логические | `and`, `or`, `not`, `&&`, `\|\|`, `!` |
| Разделители | `(`, `)`, `{`, `}`, `[`, `]`, `,`, `;`, `:`, `.` |

Буквенные и символьные логические операторы равнозначны: `and` соответствует `&&`, `or` — `||`, `not` — `!`. Составные операторы записываются без пробелов между символами. В текущем синтаксисе используются арифметические операторы `+`, `-`, `*`, `/`, `%`, `^`, присваивание `=` и разделители из EBNF-грамматики.

### Комментарии

Однострочный комментарий начинается с `//` и продолжается до конца строки или файла. Многострочный комментарий начинается с `/*` и заканчивается на первом `*/`. Вложенные комментарии не поддерживаются. Незакрытый многострочный комментарий считается ошибкой.

Внутри строк обозначения комментариев считаются обычным текстом.

### Пробельные символы

Вне строк пропускаются все символы, для которых метод .NET `char.IsWhiteSpace` возвращает `true`: пробелы, табуляции, переводы строк, неразрывный пробел, вертикальная табуляция, перевод страницы и другие пробельные символы Unicode. Поддерживаются переводы строк LF и CRLF. Внутри строк пробельные символы сохраняются.

## Синтаксис

Программа содержит ноль или более определений функций и ровно один блок `main`, расположенный после них. Функции могут вызывать функции, определённые ниже. Вложенные определения функций и глобальные переменные не поддерживаются.

Внутри блока разрешены объявления переменных, выражения с точкой с запятой, `print`, `return` и вложенные блоки. Переменная объявляется с типом и начальным значением: `int x = 3;`. В определении функции указываются возвращаемый тип (`int` или `void`), имя, параметры вида `int x` и тело в фигурных скобках.

### EBNF-грамматика

Грамматика записана в диалекте ISO EBNF. Строки в кавычках соответствуют лексемам из раздела «Лексика». Специальные последовательности `? integer literal token ?` и `? identifier token ?` обозначают соответственно целочисленный литерал и идентификатор; их лексические правила здесь не повторяются.

```ebnf
program = { functionDeclaration }, "main", block ;
functionDeclaration = ("int" | "void"), ? identifier token ?,
                      "(", [ parameterList ], ")", block ;
parameterList = parameter, { ",", parameter } ;
parameter = "int", ? identifier token ? ;

block = "{", { statement }, "}" ;
statement = variableDeclaration | block
          | "print", expression, ";"
          | "return", [ expression ], ";"
          | expression, ";" ;
variableDeclaration = "int", ? identifier token ?, "=", expression, ";" ;

expression = assignment ;
assignment = additive, [ "=", assignment ] ;
additive = multiplicative, { ("+" | "-"), multiplicative } ;
multiplicative = unary, { ("*" | "/" | "%"), unary } ;
unary = [ "-" ], power ;
power = primary, [ "^", unary ] ;
primary = ? integer literal token ?
        | ? identifier token ?, [ callArguments ]
        | "readInt", "(", ")"
        | "(", expression, ")" ;
callArguments = "(", [ argumentList ], ")" ;
argumentList = expression, { ",", expression } ;
```

При наличии `=` левая часть должна обозначать переменную. Скобки вокруг её имени разрешены: `(x) = 3`. Литерал, вызов функции и результат арифметической операции не могут быть целью присваивания. Присваивание возвращает записанное значение; `a = b = 3` разбирается как `a = (b = 3)`.

Левой рекурсии нет: рекурсивные вызовы для присваивания и степени следуют после потребления оператора. Начало альтернатив `statement` различается по ключевому слову или виду лексемы; чтение переменной и вызов функции объединены общей частью с идентификатором.

### Таблица операторов

Операторы перечислены в порядке возрастания приоритета (от низшего к высшему).

| Приоритет | Операторы | Описание | Ассоциативность |
|---|---|---|---|
| 0 (низший) | `=` | Присваивание | Правая |
| 1 | `+`, `-` | Сложение, вычитание | Левая |
| 2 | `*`, `/`, `%` | Умножение, деление, остаток от деления | Левая |
| 3 | `-` (унарный) | Унарный минус | Не применяется (унарный оператор) |
| 4 (высший) | `^` | Возведение в степень | Правая |

### Семантика вычислений

Числовые выражения имеют целочисленный тип со знаковым 64-битным представлением (`long` в C#). Вызовы функций `void` значения не имеют. Арифметические операции выполняются с проверкой переполнения. При переполнении, делении на ноль, отрицательном показателе степени, ошибке чтения или некорректном вводе интерпретатор прекращает выполнение с сообщением об ошибке.

Программа сначала целиком разбирается в абстрактное синтаксическое дерево, и только затем выполняется. Поэтому при синтаксической ошибке ни одна инструкция не выполняется и вывод не производится. Ошибки времени выполнения возникают при обходе дерева: вывод инструкций, выполненных до ошибки, сохраняется, а последующие инструкции не выполняются.

Деление `/` является целочисленным и отбрасывает дробную часть в сторону нуля. Оператор `%` возвращает остаток от целочисленного деления. Возведение в степень `^` принимает неотрицательный целочисленный показатель; для `0 ^ 0` результат равен `1`.

`readInt()` читает одну строку из `stdin` и преобразует её в десятичное знаковое 64-битное целое число. Допускаются знак `+` или `-` и пробельные символы по краям строки. Конец потока или строка, не представляющая целое число в диапазоне `long`, являются ошибкой выполнения.

Инструкция-выражение вычисляет результат, но не выводит его. Инструкция `print` выводит результат выражения в `stdout`, завершая его переводом строки.

### Переменные и области видимости

Переменные хранят значения `int` (знаковое 64-битное целое). Инициализация обязательна. Чтение и присваивание необъявленной переменной — ошибка. Объявление начинает действовать после вычисления начального значения: во вложенном блоке `int x = x + 1;` использует внешний `x`, если он существует.

Области видимости лексические. Каждый блок создаёт вложенную область; после выхода из него его переменные недоступны. Присваивание изменяет ближайшую видимую переменную. Повторное объявление в одной области запрещено, а перекрытие имени во вложенном блоке разрешено. Параметры и переменные верхнего уровня тела функции находятся в одной области.

Функции и переменные имеют отдельные пространства имён: допустимы переменная `f` и функция `f()`. Имена нечувствительны к регистру. Функция видит свои параметры и локальные переменные, но не переменные `main` или вызывающей функции. Глобальных переменных нет.

### Функции и возврат

Имена пользовательских функций должны быть уникальны; перегрузка и переопределение встроенных функций запрещены. Повторяющиеся имена параметров также запрещены. Эти ошибки определений обнаруживаются до запуска `main`.

Аргументы вычисляются слева направо и передаются по значению. Сначала проверяются наличие функции и число аргументов, затем вычисляются аргументы, после чего выполняется тело. Изменение параметра не изменяет переменную вызывающей стороны. Глубина вложенных вызовов пользовательских функций ограничена 128; превышение — ошибка выполнения.

`return expression;` завершает функцию `int` и возвращает значение. Если такая функция дошла до конца тела или выполнила `return;`, возникает ошибка. Функция `void` завершается при `return;` либо при достижении конца тела. `return expression;` в функции `void` запрещён. Возврат из вложенного блока завершает всю функцию. В `main` использовать `return` нельзя.

Вызов функции `void` разрешён как отдельная инструкция. Использование его результата в арифметике, `print`, присваивании, инициализации, аргументе или возврате значения — ошибка. Ошибки имён, аргументов и возврата, кроме ошибок определений выше, обнаруживаются при выполнении соответствующей инструкции.

### Встроенные функции

| Функция | Аргументы | Результат |
| --- | --- | --- |
| `readInt()` | Нет | Одно целое число из строки stdin |
| `abs(x)` | Одно целое | Модуль; для минимального `int` — ошибка переполнения |
| `min(x, ...)` | Одно или более целых | Наименьшее значение |
| `max(x, ...)` | Одно или более целых | Наибольшее значение |

Функции `abs`, `min`, `max` подчиняются тому же порядку вычисления аргументов, что и пользовательские функции. Они не изменяют переданные переменные.

### Пример

```text
int add(int a, int b) {
    return a + b;
}

main {
    int x = readInt();
    int y = 0;
    y = x = add(x, 2);
    print max(x, y, 10);
}
```

При вводе `5` программа выводит `10`. Полные примеры: `examples/rectangle.ck` вычисляет площадь прямоугольника по двум точкам, `examples/order.ck` — стоимость двух покупок с доставкой.
