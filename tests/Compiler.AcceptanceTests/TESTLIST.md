# Приёмочные тесты интерпретатора

Тесты вызывают `Program.Run`, как и консольная точка входа `Main`. Исходный код читается из временного файла, `StringReader` задаёт stdin, два `StringWriter` перехватывают stdout и stderr. Выполняются лексер и парсер, проверяются вывод, диагностика и код завершения.

Параметризованные сценарии находятся в `InterpreterTests.cs`. Класс `SourceFile` создаёт отдельный файл для каждого теста и удаляет его после завершения.

## Правила и альтернативы EBNF

| Правило | Проверяемые варианты | Примеры из `ValidPrograms` |
| --- | --- | --- |
| `program` | Один `main`, пустой блок и несколько инструкций | `main {}`, `main { print 1; 2 + 3; print 4; }` |
| `statement` | Выражение без вывода; инструкция `print` | `main { 2 + 3; }`, `main { print 42; }` |
| `expression` | Переход к арифметическому выражению | `main { print 2 + 3; }` |
| `additive` | Без продолжения; `+`; `-`; левая ассоциативность | `42`, `2 + 3`, `10 - 3 - 2` |
| `multiplicative` | Без продолжения; `*`; `/`; `%`; левая ассоциативность | `42`, `2 + 3 * 4`, `20 / 5 / 2`, `17 % 5` |
| `unary` | С минусом и без него; приоритет ниже степени | `42`, `-(5 + 3)`, `-2 ^ 2` |
| `power` | Без степени; степень; правая ассоциативность | `42`, `(-2) ^ 2`, `2 ^ 3 ^ 2` |
| `primary` | Целочисленный литерал; `readInt()`; выражение в скобках | `42`, `readInt()`, `(2 + 3) * 4` |

## Корректные программы

- Пример из задания с ожидаемым результатом 80.
- Вычисление площади прямоугольника по двум числам из stdin: 6 и 7 дают 42.
- Приоритеты операций, скобки, левая ассоциативность вычитания и деления, правая ассоциативность степени.
- Отрицательные операнды деления и остатка; целочисленное деление округляется к нулю.
- Выражения без `print` выполняются без вывода; несколько инструкций выполняются по порядку.
- Вызовы `readInt()` читают отдельные строки слева направо, в том числе в инструкции без вывода.
- Ключевые слова в верхнем регистре, ведущие нули, комментарии, CRLF, NBSP, вертикальная табуляция и перевод страницы.
- Границы long: максимальный литерал, минимальное значение из ввода, выражения и степени.
- `0 ^ 0`, нулевой показатель, большие показатели при основаниях 0, 1 и -1; чётность показателя при основании -1.

## Ошибки

- Отсутствие `main`, открывающей/закрывающей скобки или точки с запятой, незакрытые круглые скобки, второй `main`, пустое выражение.
- Неподдерживаемые переменные, вещественные/строковые/логические литералы.
- Неизвестный символ и незакрытый комментарий.
- Деление и остаток от деления на ноль, отрицательная степень, слишком большой литерал.
- Переполнение сложения, вычитания, умножения, деления, остатка, унарного минуса и степени.
- EOF при вводе, пустая строка, текст, дробь, переполнение и два числа на одной строке.
- После синтаксической ошибки, ошибки арифметики или ввода последующие инструкции не выполняются. Вывод предшествующих инструкций сохраняется.
- Отсутствующий/лишний аргумент CLI, отсутствующие файл и каталог, каталог вместо файла.

Для ошибки ожидаются код 1, диагностическое сообщение в stderr и только тот stdout, который программа успела сформировать до ошибки.

## Запуск и покрытие

```sh
dotnet test tests/Compiler.AcceptanceTests
```

Скрипты `scripts/run-tests-with-coverage.ps1` и `scripts/run-tests-with-coverage` создают HTML-отчёт `tests/coverage-report/index.html`. Line coverage класса `Parsing.Parser` должно быть не ниже 80%. Результаты проверки приведены в [COVERAGE.md](COVERAGE.md).
