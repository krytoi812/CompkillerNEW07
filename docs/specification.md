# CompkillerNEW07

## Введение

CompkillerNEW07 — учебный императивный язык программирования со строгой типизацией. Он предназначен для написания небольших программ в одном файле и ориентирован на простоту реализации и понимания.

По стилю язык похож на C, C++, C# и Pascal: в нём есть явная точка входа `main`, переменные объявляются явно, поддерживаются условия, циклы, функции и базовые структуры данных. При этом язык остаётся минималистичным: в первой версии не предполагается лишних возможностей, которые усложняют реализацию.

Основные особенности языка:

- одна программа хранится в одном файле;
- есть точка входа `main`;
- язык строго типизирован;
- поддерживаются числовой, строковый и логический типы;
- есть арифметические, логические и сравнительные операторы;
- есть оператор присваивания;
- есть переменные с явным объявлением;
- есть ветвления, циклы и последовательное выполнение инструкций;
- поддерживаются массивы;
- поддерживаются структуры или классы;
- поддерживается процедурный стиль программирования.

## Лексика

Лексическая структура языка описывает, из каких лексем состоит исходный текст программы и как они распознаются.

### Идентификаторы

Идентификаторы используются для имён переменных, функций, структур, классов и других пользовательских сущностей.

Правила записи идентификатора:

- начинается с буквы или символа `_`;
- далее могут идти буквы, цифры и `_`;
- регистр символов не учитывается.

Примеры:

```text
x
summa
_counterspEll
BaSHmAK
```

### Ключевые слова

Ключевые слова имеют фиксированное значение и не могут использоваться как идентификаторы.

Пример набора ключевых слов:

```text
main
if
else
while
for
return
var
true
false
struct
class
```

### Литералы

#### Числовые литералы

Числовые литералы задают целые или вещественные значения.

Примеры:

```text
314
3.14
0
```

#### Строковые литералы

Строковые литералы записываются в двойных кавычках.

Примеры:

```text
"Hello, world!"
"Привет, мир!"
```

Внутри строк допускаются управляющие последовательности, например `\\`, `\"`, `\n`, `\t`.

#### Логические литералы

Логические значения записываются как:

```text
true
false
```

### Операторы

В языке поддерживаются следующие группы операторов.

Арифметические:

```text
+
-
*
/
%
```

Оператор присваивания:

```text
=
```

Логические:

```text
and
or
not
&&
||
!
```

Операторы сравнения:

```text
==
!=
<
<=
>
>=
```

Если в языке используются буквенные и символьные формы логических операторов, они считаются синонимами.

### Разделители

В языке используются следующие разделители:

```text
(
)
{
}
[
]
,
;
:
.
```

### Комментарии

Комментарии используются для пояснений в коде и игнорируются компилятором.

Поддерживаются два вида комментариев:

```text
// однострочный комментарий
/* многострочный комментарий */
```

### Пробелы и переносы строк

Пробелы, табуляции и переносы строк используются как разделители лексем и не имеют самостоятельного значения, кроме случаев, когда они входят внутрь строковых литералов.

### Чувствительность к регистру

Язык не чувствителен к регистру символов.

### Итог

Лексический анализатор языка должен распознавать идентификаторы, ключевые слова, литералы, операторы, разделители и комментарии в соответствии с правилами выше.
